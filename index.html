คู่มือการนำขึ้น GitHub Pages (3 นาที)

ขั้นตอนการสร้างเว็บไซต์แสดงผลฟรีถาวรบน GitHub

ขั้นตอนที่ 1: บันทึกไฟล์นี้

บันทึกโค้ดนี้ทั้งหมดลงในคอมพิวเตอร์ของคุณ ตั้งชื่อไฟล์ว่า index.html

ขั้นตอนที่ 2: สร้าง Repository บน GitHub

  1. เข้าเว็บไซต์ GitHub.com แล้วล็อกอิน
  2. กดปุ่ม **New Repository**
  3. ตั้งชื่อ Repository เช่น academic-portfolio หรือ username.github.io
  4. เลือกประเภทเป็น **Public** แล้วกด **Create repository**

ขั้นตอนที่ 3: อัปโหลด index.html และเปิดใช้ GitHub Pages

  1. กดปุ่ม **uploading an existing file** แล้วลากไฟล์ index.html ไปวาง
  2. กดปุ่ม **Commit changes**
  3. ไปที่เมนู **Settings** > **Pages** ด้านซ้ายมือ
  4. ในส่วน **Build and deployment / Branch** เปลี่ยนเป็น main แล้วกด **Save**

สำเร็จ!
